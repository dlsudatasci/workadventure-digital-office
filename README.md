Mini Mckinley is HXIL and ALTDSI's first ever web-based digital office proudly hosted on the ALTDSI server.

### 🚀 Key Features

* 🌐 **Global Accessibility** — Step into the digital office from anywhere via [<kbd>&nbsp;wa.altdsi.com&nbsp;</kbd>](https://wa.altdsi.com)
* ⚡ **Real-time Interaction** — Collaborate instantly with team members in a dynamic digital environment as if you were.
* 💬 **Seamless Communication** — Built-in support for proximity-based audio/video calls, presentations, shared whiteboards, and localized chat spaces.
